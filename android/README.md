<div align="center">

**سازگار با:** اندروید ۷.۰ به بالا (API 24 تا API 36)  
**معماری:** Native Android (Java) + Hardware-Accelerated Core + Cloudflare Edge Integration

## 🧭 معماری از نسخهٔ ۱.۶

| موضوع | روش |
|---|---|
| **رابط کاربری** | در `MainActivity` (WebView) از خود سرور بارگذاری می‌شود، پس با به‌روزرسانی سرور عوض می‌شود و نسخهٔ تازهٔ APK نمی‌خواهد. |
| **اعلان با برنامهٔ بسته** | سرویس پیش‌زمینهٔ `WihmNotificationService` یک WebSocket دائمی به `/api/ws/inbox` نگه می‌دارد. به Chrome یا خدمات گوگل وابسته نیست. |
| **تماس ورودی** | سرویس خودش زنگ و لرزش را پخش می‌کند و صفحهٔ تمام‌صفحهٔ `IncomingCallActivity` را باز می‌کند. دکمهٔ پاسخ برنامه را باز می‌کند و صفحه تماس را می‌پذیرد. |
| **قطع اتصال** | سرویس خودش دوباره وصل می‌شود، هر ۲ دقیقه و با هر تغییر شبکه اتصال را آزمایش می‌کند و تا وصل شدن هر ۶۰ ثانیه پیام‌ها را بررسی می‌کند. |
| **به‌روزرسانی APK** | فقط برای تغییر کد بومی یا مجوزها لازم است. برنامه آخرین انتشار مشترک را از ریپوی عمومی WIHM-Cloudflare می‌خواند. |

| **صدای تماس** | `CallAudio` صدا را بین گوشی و بلندگو عوض می‌کند و نزدیک گوش صفحه را خاموش می‌کند. |
| **پراکسی** | `ProxySettings` پراکسی SOCKS5 یا HTTP را برای WebView و سرویس اعمال می‌کند. MTProto پشتیبانی نمی‌شود، چون فقط پروتکل تلگرام را حمل می‌کند. |
| **فایل** | `FileDownload` فایل را با نشست کاربر در Downloads ذخیره می‌کند. |

برای کار پایدار، کاربر باید محدودیت باتری را بردارد. برنامه این را یک بار پس از ورود می‌پرسد. در گوشی‌های شیائومی و مشابه، اجازهٔ شروع خودکار هم لازم است.

آزمون سرتاسری روی شبیه‌ساز در `tests/android/emulator-e2e.mjs` ریپوی WIHM-Cloudflare است و نسخهٔ `assembleQa` را اجرا می‌کند.

برای انتشار، `versionCode` را در `app/build.gradle` افزایش دهید. `versionName` از `package.json` ریشه خوانده می‌شود و یک APK یونیورسال همراه سرور و ویندوز با تگ `installer-v<نسخه>` منتشر می‌شود.

کلید امضا در این ریپو نیست. CI آن را از GitHub Secrets می‌خواند و بیلد محلی از فایل نادیده‌گرفته‌شدهٔ `android/keystore.properties`. بدون این‌ها بیلد با کلید debug امضا می‌شود.

## 📌 معرفی پروژه

این پروژه کلاینت بومی و **فوق‌سبک (Ultra-Lightweight)** برای پیام‌رسان ابری **[WIHM-Cloudflare (ابرانه)](https://github.com/DarkPoesidon/WIHM-Cloudflare)** است.

در مقایسه با پیام‌رسان‌های متداول نظیر تلگرام (نسخه رسمی اندروید ~۷۵ تا ۱۰۰ مگابایت) یا برنامه‌های مبتنی بر کراس‌پلتفرم سنگین مانند Flutter و React Native (با حجم ۳۰ تا ۶۰ مگابایت)، این اپلیکیشن با مهندسی معکوس الگوهای بهینه و حذف تمامی وابستگی‌های زائد، با حجم **فقط ۱.۶ مگابایت (بیش از ۹۸٪ سبک‌تر)** پیاده‌سازی شده است.

## ✨ ویژگی‌های کلیدی

- **⚡ ارتباط زنده و بلادرنگ (Real-time WebSocket):**
  - اتصال پیوسته به Cloudflare Durable Objects با پایداری بالا
  - صف ارسال پیام در حالت آفلاین و ارسال خودکار پس از اتصال مجدد
  - نمایش وضعیت پیام‌ها (ارسال، تحویل، مشاهده) و نشانگر «در حال نوشتن»
  - شمارندهٔ پیام‌های خوانده‌نشده
- **👥 مدیریت گفتگوها و گروه‌ها:**
  - گفتگوی دوطرفه خصوصی و گروه‌ها با سطوح دسترسی (مالک، مدیر، عضو)
  - پیام‌های سنجاق‌شده (Pin) و پیام‌های ذخیره‌شده (Saved Messages)
  - پاسخ (Reply)، ویرایش (Edit)، حذف (Delete) و واکنش (Reactions) با ایموجی
- **📢 یکپارچگی با کانال‌های تلگرام (Telegram Integration):**
  - خواندن پست‌های کانال‌های عمومی تلگرام بدون نیاز به عضویت یا دانلود مدیا روی سرور
  - پشتیبانی از اتصال ربات تلگرام برای کانال‌های خصوصی و مدیریت‌شده
  - تشخیص خودکار نصب بودن تلگرام روی گوشی و هدایت مستقیم پیوندهای `t.me` به اپ رسمی تلگرام
- **🎙️ ارسال و پخش صدا (Voice Messages):**
  - ضبط صوت با درخواست مجوز بومی `RECORD_AUDIO` در اندروید
  - پخش صدای روان و بدون قطعی
- **🔔 اعلان‌های بومی و سرویس زنده در پس‌زمینه (Background Notifications & Keep-Alive):**
  - سرویس پیش‌زمینهٔ بومی `WihmNotificationService` (مشابه Telegram NotificationsService) که با بسته شدن اپلیکیشن یا خاموش شدن صفحه متوقف نمی‌شود.
  - پشتیبانی کامل از Doze Mode و درخواست لغو محدودیت باتری (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`).
  - دکمهٔ بازکردن مستقیم تنظیمات راه‌اندازی خودکار (Autostart) برای گوشی‌های شیائومی، سامسونگ و هواوی.
  - گیرندهٔ `BootReceiver` جهت شروع خودکار سرویس پس از روشن شدن یا راه‌اندازی مجدد گوشی.
  - بخش جامع تنظیمات اعلان بومی اندروید در صفحه «تنظیمات ← اعلان‌ها».
- **🚀 فیزیک اسکرول روان و بدون لگ (Inertial Momentum Scrolling):**
  - شتاب‌دهی سخت‌افزاری مستقیم (Hardware Acceleration)
  - حذف لایه‌های زائد و رفع ۱۰۰٪ باگ ری‌لود شدن و بسته‌شدن منوها هنگام اسکرول
- **🌐 مدیریت و تغییر آسان سرور کلادفلر:**
  - امکان تغییر نشانی ورکر در هر لحظه از منوی همبرگری و تنظیمات
  - دکمه تست آنلاین اتصال و قابلیت پاک‌سازی نشست (Reset Cache)
  - قابلیت تغییر سرور قبل از ورود در صفحه لاگین

## 🛠️ ساخت از سورس (Build from Source)

### پیش‌نیازها:
- JDK 17 یا بالاتر
- Android SDK (API 34)

### کامپایل نسخه Debug:
```bash
./gradlew assembleDebug
```

### کامپایل نسخه نهایی بهینه‌سازی‌شده Release:
```bash
./gradlew assembleRelease
```
فایل نهایی در مسیر `app/build/outputs/apk/release/app-release.apk` تولید می‌شود.
