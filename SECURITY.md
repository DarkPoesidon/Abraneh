# Security

Please report security problems **privately**, not in public issues: open the repository's **Security** tab and choose **Report a vulnerability**, or use [this link](https://github.com/DarkPoesidon/Abraneh/security/advisories/new).

Include the version, what you did and what happened. Never include real access tokens, passwords, admin codes or other people's messages.

Only official releases from https://github.com/DarkPoesidon/Abraneh/releases are supported. See "Official sources" in the [README](README.md) to check that a file is genuine.
