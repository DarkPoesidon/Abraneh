پیام‌رسان روی حساب کلادفلر شما اجرا می‌شود. بعد از نصب، روشن ماندن این دستگاه لازم نیست.

نشانی نصب‌کننده کامل نیست. لینک نمایش‌داده‌شده در پنجرهٔ نصب را دوباره باز کنید.

پیام‌رسانت را راه بینداز.

یک بار به کلادفلر دسترسی بده؛ ساخت دیتابیس، تنظیمات و انتشار را ما انجام می‌دهیم.

اجازهٔ نصب را بگیر

کلادفلر برای نصب به یک کد دسترسی به نام API Token نیاز دارد. رمز حساب خودت را اینجا وارد نکن.

ساخت کد دسترسی ↗
  1. دکمهٔ بالا را بزن و وارد کلادفلر شو. مجوزهای لازم در فرم آماده‌اند.
  2. در Account Resources حساب خودت را انتخاب کن؛ سپس Continue to summary و Create Token را بزن.
  3. کد را کپی کن و در کادر پایین بچسبان. اگر بعد از ورود، فرم آماده را ندیدی، دوباره دکمهٔ بالا را بزن.
اگر فرم آماده باز نشد
  1. وارد حساب کلادفلر شو. اگر حساب نداری، حساب بساز و ایمیل را تأیید کن.
  2. در صفحهٔ بازشده، Create Token و سپس Create Custom Token را بزن.
  3. نام را WIHM Installer بگذار و این سه مجوز را اضافه کن:

Account → Account Settings → Read

Account → Workers Scripts → Edit

Account → D1 → Edit

  1. در Account Resources، گزینهٔ Include → Specific account و حساب خودت را انتخاب کن.
  2. Continue to summary و Create Token را بزن. کد را کپی کن و به همین صفحه برگرد.

کد فقط در حافظهٔ این نصب‌کننده نگه داشته می‌شود و در فایل ذخیره نمی‌شود.

یک نام برای آدرس انتخاب کن.

این نام بخشی از لینک پیام‌رسان می‌شود. بقیهٔ تنظیمات را نصب‌کننده می‌سازد.

۳ تا ۴۰ حرف کوچک انگلیسی، عدد یا خط تیره؛ مثل my-family-chat.

در حال آماده‌کردن پیام‌رسان…

این صفحه و پنجرهٔ نصب را تا پایان کار باز نگه دار.

  1. بررسی حساب و نصب قبلی
  2. آماده‌کردن آدرس اینترنتی
  3. ساخت یا اتصال دیتابیس
  4. آماده‌کردن جدول‌ها
  5. بارگذاری رابط پیام‌رسان
  6. تنظیم کلید امنیتی و انتشار
  7. بررسی سلامت پیام‌رسان

این مرحله کامل نشد.

اطلاعات ساخته‌شده حفظ می‌شود. بعد از رفع مشکل دوباره تلاش کن.

پیام‌رسان آماده است.

لینک را باز کن و حساب کاربری پیام‌رسانت را بساز. برای دعوت دیگران همین لینک را بفرست.

باز کردن پیام‌رسان ↗

فعال‌سازی مدیر سرویس

با حساب خودت وارد پیام‌رسان شو؛ «تنظیمات ← مدیریت سرویس» را باز کن و این کد را وارد کن. کد را برای دیگران نفرست. اگر مدیر را قبلاً فعال کرده‌ای نیازی به تکرار نیست.

از منوی مرورگر، «نصب برنامه» یا «افزودن به صفحهٔ اصلی» را انتخاب کن. بعد از پایان نصب می‌توانی توکن را از صفحهٔ API Tokens کلادفلر حذف کنی؛ پیام‌رسان فعال می‌ماند.

نصب‌کننده بسته شد.
