این صفحه دیگر به‌روز نمی‌شود. همهٔ مطالب آن، به‌روز و قدم‌به‌قدم، در دو راهنمای اصلی آمده است:

| دنبال چه هستید؟ | کجا بخوانید |
| --- | --- |
| معنی حساب کلادفلر، کد دسترسی، حساب پیام‌رسان و کد مدیریت | [چند کلمه که باید بشناسید](GUIDE-ADMIN.fa.md#words) |
| ساختن سرور از صفر | [راهنمای صاحب سرور](GUIDE-ADMIN.fa.md#step-1) |
| ساخت حساب و نصب برنامه | [راهنمای کاربران](GUIDE-USER.fa.md#account) |
| به‌روزرسانی | [سرور](GUIDE-ADMIN.fa.md#update) · [برنامه‌ها](GUIDE-USER.fa.md#updates) |

- **می‌خواهم پیام‌رسان بسازم:** [راهنمای صاحب سرور](GUIDE-ADMIN.fa.md)
- **لینک پیام‌رسان را گرفته‌ام:** [راهنمای کاربران](GUIDE-USER.fa.md)
