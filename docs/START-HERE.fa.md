# از اینجا شروع کنید

> **راهنماهای تازه و کامل:** [صاحب سرور](GUIDE-ADMIN.fa.md) · [کاربران](GUIDE-USER.fa.md). این صفحه و راهنماهای جزئی‌تر، بعضی جاها نسخه‌های قدیمی‌تر را توصیف می‌کنند.

این راهنما برای **ابرانه / WIHM Cloudflare** است. برای نصب معمولی، برنامه‌نویسی، VPS، Git و ویرایش فایل لازم نیست.

## کدام راهنما را بخوانم؟

| وضعیت شما | از اینجا شروع کنید |
| --- | --- |
| می‌خواهم برای خودم و دوستانم پیام‌رسان بسازم | [نصب خودکار از صفر](EASY-INSTALL.fa.md) |
| فقط لینک پیام‌رسان را از کسی گرفته‌ام | [ثبت‌نام و استفاده از برنامه](DAILY-USE.fa.md)؛ کلادفلر و ترموکس لازم ندارید |
| نصب قبلی دارم و نسخهٔ تازه می‌خواهم | [آپدیت دستگاه و سرور](AUTO-UPDATE.fa.md) |

اگر تازه‌کار هستید، [نصب خودکار](EASY-INSTALL.fa.md) را انتخاب کنید. [نصب دستی](INSTALL.fa.md) مسیر فنیِ جداگانه است و برای نصب‌کننده لازم نیست.

<a id="چهار-چیز-متفاوت"></a>

## چهار چیز متفاوت

۱. **حساب کلادفلر:** حساب صاحب سرویس برای میزبانی برنامه. کاربران عادی به آن نیاز ندارند.

۲. **توکن کلادفلر / API Token:** کد اجازهٔ نصب یا آپدیت؛ رمز پیام‌رسان نیست و نباید برای دیگران فرستاده شود.

۳. **حساب پیام‌رسان:** نام کاربری و رمز شخصی که بعد از نصب، داخل ابرانه می‌سازید. نصب‌کننده حساب آماده یا رمز عمومی نمی‌سازد.

۴. **کد مدیریت سرویس:** کد پایان نصب، برای مدیرکردن حساب پیام‌رسانِ صاحب سرویس. اولین ثبت‌نام‌کننده خودکار مدیر نیست.

## لینک‌ها را اشتباه نگیرید

| نمونه | کاربرد |
| --- | --- |
| `http://127.0.0.1:.../#...` | صفحهٔ خصوصی نصب روی همان دستگاه؛ برای دوستان نفرستید |
| `https://my-chat.account.workers.dev` | لینک عمومی برنامه؛ بعد از نصب برای کاربران می‌فرستید |
| `sara@my-chat.account.workers.dev` | نشانی کاربر برای ارتباط بین سرورها؛ آدرس ایمیل نیست |

این‌ها مثال‌اند؛ لینک واقعی را نصب‌کننده نشان می‌دهد.

## ترتیب پیشنهادی برای صاحب سرویس

۱. [نصب خودکار](EASY-INSTALL.fa.md) را انجام دهید، حساب بسازید و مدیریت را فعال کنید.

۲. با کمک [راهنمای برنامه](DAILY-USE.fa.md) یک پیام رفت‌وبرگشت با دوستتان آزمایش کنید.

۳. [آپدیت](AUTO-UPDATE.fa.md) و [پشتیبان](ADVANCED.fa.md#پشتیبان-کامل-سرور-و-بازیابی) را قبل از نیاز آماده کنید.

۴. سپس بقیهٔ [امکانات پیشرفته](ADVANCED.fa.md) و [اتصال تلگرام](TELEGRAM.fa.md) را راه بیندازید.

پس از پایان موفق نصب، رایانه و ترموکس می‌توانند خاموش باشند؛ سرویس روی کلادفلر می‌ماند. سقف مصرف و محدودیت‌های حساب برقرار است و نصب‌کننده طرح پولی را خودکار فعال نمی‌کند.

گفتگوی امن از دکمهٔ «+» شروع می‌شود و از MLS **آزمایشی** استفاده می‌کند؛ گفتگوهای عادی، گروه‌ها و کانال‌ها رمزگذاری سرتاسری ندارند. [تفاوت و محدودیت‌ها](ADVANCED.fa.md#معنای-رمزگذاری-آزمایشی).
