# Poster generation prompt

Tool: built-in `imagegen`.

Reference inputs: desktop and mobile screenshots of the running application using fictional demo accounts, plus the existing application icon from `public/icon.svg`.

## Final prompt

Use case: compositing / ads-marketing. Create one polished landscape product poster for the top of a Persian GitHub README, wide 16:9 composition, ideally 2048x1152. This is the WIHM Cloudflare project, a Persian text messenger. Input 1 is the REAL desktop application screenshot; Input 2 is the REAL mobile application screenshot; Input 3 is the existing application logo. Use the actual input screenshots as screen content, preserving their Persian text, controls, dark navy colors, blue message bubbles and RTL layout; do not invent or redesign the UI. Present a crisp desktop browser panel with a narrow tasteful frame and an overlapping upright phone containing the mobile screenshot. Keep devices nearly front-facing so the product remains readable, with no hand or human model. Beside the screens, create a carefully typeset Persian editorial title block with the existing app icon, exact English project label "WIHM Cloudflare", exact large Persian title "پیام‌رسان ابرانه", and exact Persian subtitle "گفتگوی خصوصی و گروهی روی کلادفلر". Small supporting labels, ONLY these three exact labels: "فارسی و راست‌چین" / "گفتگوی زنده" / "وب و موبایل". Main Persian copy is correctly shaped connected Persian, RTL and highly legible at GitHub README display size. Large clean typography with generous breathing room, a restrained premium software launch poster. Use the actual brand palette: deep navy #0f172a, azure #0284c7, slate, and ivory white; a mostly light icy-white studio backdrop makes the dark real application screens stand out, with a very subtle azure glow and simple soft shadows. The title block should respect Persian RTL reading. Strong visual hierarchy, ample safe margins, product screens occupy the main visual area. No extra copy, no decorative fake badges, no security/encryption/privacy claims, no Cloudflare corporate logo, no GitHub logo, no watermark, no extra invented app features.
