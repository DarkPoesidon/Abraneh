# WIHM Cloudflare 1.7.1

- **گیرکردن به‌روزرسانی سرور:** بعد از انتشار، کلادفلر گاهی چند دقیقه نسخهٔ قبلی را نشان می‌دهد. به‌روزرسان این را خطا می‌دانست و فاصلهٔ تلاش‌هایش تا چند دقیقه زیاد می‌شد. حالا هر ۲۰ ثانیه بررسی می‌کند، پیام روشن نشان می‌دهد، و اگر کلادفلر نسخه را فعال نکرد خودش دوباره منتشر می‌کند.
- **حذف گفتگو:** روی گفتگو نگه دارید یا راست‌کلیک کنید، یا از اطلاعات گفتگو. می‌توانید فقط برای خودتان یا برای هر دو نفر حذف کنید. برای گروه و کانال همان خروج و حذف است.

این اصلاح به‌روزرسان از به‌روزرسانی بعدی اثر می‌گذارد، چون هر نسخه با به‌روزرسان قبلی نصب می‌شود.
