# WIHM Cloudflare 1.7.17

- **بازیابی رمز:** صاحب سرور در «مدیریت کاربران» برای هر کاربر لینک بازیابی می‌سازد. لینک یک ساعت و فقط یک بار کار می‌کند، همهٔ نشست‌های کاربر را می‌بندد و ورود دومرحله‌ای را خاموش نمی‌کند.
- **فرم ثبت‌نام:** کد دومرحله‌ای و ورود با کلید عبور دیگر در ثبت‌نام نشان داده نمی‌شوند.
- **نصب‌کننده:** گزینهٔ به‌روزرسانی از داخل پیام‌رسان دیگر کشیده نمایش داده نمی‌شود.
