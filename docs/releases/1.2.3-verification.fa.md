## بستهٔ عمومی

هر دو آرشیو و `SHA256SUMS` از خود ریلیز دوباره دانلود شدند. ZIP و tar.gz شامل ۶۱ فایل با بایت‌های یکسان‌اند؛ ۵۶ فایل با سورس همان تگ تطبیق داده شدند. مسیرهای استخراج، مجوز اجرای شل، نسخه‌ها، دو migration قبلی، ۲۸ لینک نسبی مستندات و فونت وزیر بررسی شدند.

```text
9d3d7e456640e5facdd541c289fc44c137eef8a1da4c14eba08df8ce95463eda  wihm-installer.zip
252bb2b8dfd08a4fa820078404f637868756e4fed18301f41b5de7c76704e122  wihm-installer.tar.gz
```

هش Worker با متادیتای بسته و ساخت محلی مطابق است:

```text
bd09ba82c1f95f023b58f1b2e2d1a07914e8fb726c53fc6d54f6121c57464e03
```

مسیر عمومی `releases/latest/download/SHA256SUMS` بدون ورود به گیت‌هاب، همان فایل را برگرداند. از ZIP دانلودی، لانچر ویندوز با پیام‌های انگلیسی، صفحهٔ فارسی، جداسازی نشست و توقف سالم اجرا شد. بارگذار خود بسته با ۱۰ فایل واقعی برنامه، فونت و multipart چندبخشی و حالت کش‌شده نیز گذشت.

## اجرای اندروید و ترموکس

[گزارش خطاهای بازتولیدشده و تصویر Chrome اندروید](../design-notes/termux-1.2.3.fa.md).

محیط تازهٔ Android 16 / API 36 / x86_64، برنامهٔ رسمی Termux 0.118.3 و Node.js 24.22.1 مخصوص اندروید استفاده شد. هش APK رسمی x86_64 پیش از نصب بررسی شد:

```text
3550e61f4d9eb49b712fd1bd9519dc37085a4d8eb597c57a340f0a64859b7144
```

روش قدیمی روی ترموکس تازه با خطای curl/OpenSSL شکست خورد. بعد از بازنشانی فقط برنامهٔ آزمایشی ترموکس، دستور اصلاح‌شده بدون ویرایش فایل یا نصب دستی Node، ارتقای هماهنگ را انجام داد و اجرا شد. هر ۱۳ تست نصب‌کننده و شل در Node با پلتفرم `android` موفق شدند؛ رد شدن درخواست‌های خارجی و ادامهٔ نصب با همان دیتابیس نیز پوشش داده شدند.

پس از انتشار، دستور دقیق راهنمای کاربر دوباره در خود ترموکس اجرا شد؛ tar.gz عمومی ۱.۲.۳ را دانلود، checksum را تأیید و اجرا کرد. بارگذار **همان بستهٔ دانلودشده** با فایل‌ها و فونت واقعی علیه API ساختگی گذشت. لانچر **همان بسته** نیز داخل اندروید اجرا شد؛ صفحهٔ فارسی، پیام انگلیسی، نشست محلی و توقف سالم تأیید شدند.

بستهٔ عمومی از خود ترموکس Chrome را باز کرد. نسخهٔ پایین صفحه ۱.۲.۳، عرض صفحه و scrollWidth هر دو ۴۱۲ پیکسل، بدون اسکرول افقی و کد نشست از نوار آدرس حذف شده بود. فونت واقعی `Vazir` از مسیر محلی با `200 / font/woff2` و این هش دریافت شد:

```text
3d7c6820aa45e4f1c569561a7dabc6472153e14ea883b5b6ef41aa764c66def0
```

این اجرای واقعی اندروید در شبیه‌ساز است؛ گوشی فیزیکی یا ARM64 را شامل نمی‌شود. توکن حساب واقعی کلادفلر وارد نشد؛ آزمون بارگذار و استقرار از API شبیه‌سازی‌شده استفاده می‌کند. انتشار روی حساب صاحب سرویس، شبکهٔ موبایل و محدودیت باتری گوشی شواهد میدانی جداگانه می‌خواهند. سرور آزمایشی و شبیه‌ساز اختصاصی پس از بررسی بسته شدند.
