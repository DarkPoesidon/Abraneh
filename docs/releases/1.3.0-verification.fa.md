# شواهد انتشار ۱.۳.۰

تاریخ بررسی: ۲۹ اکتبر ۲۰۲۶. [ریلیز عمومی](https://github.com/DarkPoesidon/WIHM-Cloudflare/releases/tag/installer-v1.3.0) از کامیت `6646643729e0fc76587f3e92597f1f6d72b7fdd9` منتشر شد.

## آزمون کد و مرورگر

- بررسی TypeScript و ۵۵ تست پیام‌رسان موفق؛ شامل امضای معتبر/مخدوش، مجوز مدیر، تمدید توکن، توقف پس از پذیرش انتشار برنامه و خودبه‌روزرسان و ادامه با runtime تازه و ذخیره‌سازی پایدار.
- ۱۳ تست نصب‌کننده روی ویندوز موفق؛ دو آزمون شل ترموکس روی ویندوز عمداً اجرا نمی‌شوند. هر ۱۵ تست در ترموکس رسمی داخل اندروید موفق شدند.
- Chrome واقعی: «فعلاً نه» پس از بستن همهٔ تب‌ها نسخهٔ قبلی را حفظ کرد؛ تأیید، حالت دستی و انتظار خودکار برای پایان نوشتن موفق بودند.
- رابط آپدیت و تلگرام در عرض‌های ۳۲۰، ۳۷۵، ۷۶۸ و ۱۲۸۰ بدون خطای JavaScript یا خروج افقی بررسی شد؛ متن HTML پست به‌صورت متن بی‌خطر نمایش داده شد. رگرسیون امکانات روزمره شامل پاسخ، ویرایش، واکنش، سنجاق، ذخیره، جستجوی فارسی، دعوت و گروه نیز موفق بود.
- پیش‌نمایش واقعی کانال عمومی Telegram News با HTMLRewriter تجزیه و ۲۰ پست متنی تشخیص داده شد. تست مستقل وب‌هوک، رمزشدن توکن، تکرار/ترتیب ویرایش‌ها، مجوز خصوصی و قطع اتصال نیز موفق بود.

## CI و بستهٔ عمومی

[گردش‌کار انتشار](https://github.com/DarkPoesidon/WIHM-Cloudflare/actions/runs/40839127213) برای لینوکس، ویندوز و macOS و مرحلهٔ انتشار موفق است. اجرای نامنتشر اولیه به‌دلیل جاافتادن فایل مهاجرت متوقف شد؛ نسخهٔ نهایی بالا شامل مهاجرت ۰۰۰۳ است.

هر پنج فایل از خود ریلیز عمومی دوباره دانلود شد. دو آرشیو دقیقاً ۷۱ فایل یکسان دارند؛ ۶۵ فایل قابل تطبیق با سورس تگ مقایسه و ۴۶ لینک نسبی راهنما داخل بسته بررسی شد. امضای Ed25519 با کلید عمومی پین‌شده، ساختار بسته با اعتبارسنج واقعی برنامه و برابری تمام ۱۸ فایل آپدیت با payload آرشیو تأیید شدند. sourceCommit بسته همان کامیت تگ است. لینک بدون ورود `latest/download/SHA256SUMS` نیز دقیقاً به همان فهرست هش رسید.

## مرز نتیجه

استقرار/خودبه‌روزرسانی روی حساب واقعی کلادفلر، دریافت وب‌هوک یک کانال خصوصی واقعی و تحویل اعلان به گوشی فیزیکی در این دور آزمایش نشده‌اند. تست‌های Cloudflare و Bot API از شبیه‌سازی پاسخ سرویس استفاده می‌کنند؛ تست مرورگر و اجرای ترموکس واقعی‌اند. سهمیه، انقضای توکن، دسترسی شبکه و هزینه تابع حساب و محیط کاربر هستند. پشتیبان کامل و rollback خودکار جزء این ریلیز نیستند.
