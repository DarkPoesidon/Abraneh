# WIHM Cloudflare 1.4.0

بخش نخست اولویت سوم: مدیریت سرویس و پیدا کردن کاربران بین سرورهای مستقل.

- **تنظیمات ← مدیریت سرویس ← وضعیت و مدیریت کاربران**: آمار سرویس، جستجو و صفحه‌بندی کاربران، غیرفعال/فعال‌کردن حساب، رویدادهای مدیریت و گزارش عیب‌یابی بدون رمز و توکن.
- غیرفعال‌کردن حساب، نشست‌های قبلی و ورود تازه را می‌بندد؛ فعال‌کردن دوباره به ورود تازه نیاز دارد. پیام‌ها حذف نمی‌شوند و حساب مدیر قابل غیرفعال‌کردن نیست.
- **تنظیمات ← کاربران سرورهای دیگر**: پیدا کردن کاربر با نشانی دقیق `username@server`؛ نمایش پروفایل فقط با رضایت مدیر سرور و خود کاربر، پیش‌فرض خاموش. دادهٔ عمومی فقط نام و نشانی است.
- مقصدهای workers.dev مستقیم جستجو می‌شوند؛ دامنهٔ اختصاصی مقصد باید ابتدا در فهرست مجاز مدیر ثبت شود. IP، پورت و redirect دلخواه پذیرفته نمی‌شوند؛ توکن ورود به مقصد فرستاده نمی‌شود.
- مهاجرت ۰۰۰۴ خودکار و بدون حذف پیام‌ها؛ نصب موجود با همان حساب و نام ارتقا می‌یابد. به‌روزرسانی داخل برنامهٔ ۱.۳ همچنان قابل استفاده است.

**محدودهٔ این نسخه:** جستجوی بین سرورها فعال است؛ ارسال پیام بین سرورها و E2EE هنوز فعال نیستند. پشتیبان/بازیابی کامل، اتصال خودکار دامنه و ادامهٔ امنیت/فدراسیون در اولویت سوم باقی مانده‌اند؛ این اولویت کامل‌شده اعلام نمی‌شود. آمار رابط، مصرف صورتحساب یا سهمیهٔ کلادفلر نیست و گزارش عیب‌یابی پشتیبان نیست.
