# WIHM Cloudflare 1.5.1

- اصلاح کامل پنجرهٔ تماس: وسط صفحه، رنگ متن خوانا، آواتار مخاطب، پیش‌نمایش کوچک دوربین و حذف دو پخش‌کنندهٔ ویدئوی خالی در تماس صوتی.
- کنترل میکروفون، صدای مخاطب، دوربین و مدت تماس؛ پیام روشن برای مجوز ردشده یا دستگاه اشغال‌شده.
- دریافت تماس ورودی در بخش‌های دیگر برنامه و بدون باز کردن قبلی گفتگو؛ پذیرش، گفتگو و اتصال لازم را آماده می‌کند. رد و لغو تماس نیز به فرستنده می‌رسد.
- اعلان کوتاه‌عمر تماس از همان مسیر Web Push، با رعایت مجوز اعلان، بی‌صدا کردن گفتگو، مسدودسازی و اعتبار نشست.
- واسط Cloudflare TURN برای شبکه‌های محدود: «تنظیمات ← مدیریت سرویس ← تنظیم اتصال تماس (TURN)». مدیر یک بار TURN Key ID و API Token همان کلید را وارد می‌کند؛ نیازی به ویرایش فایل نیست. اعتبار کلید پیش از ذخیره بررسی می‌شود، توکن اصلی رمزگذاری‌شده در سرور می‌ماند و کاربران مجوز موقت دریافت می‌کنند. مصرف واسط تابع تعرفهٔ کلادفلر است.

ابتدا **سرور** را به ۱.۵.۱ ارتقا دهید و سپس به‌روزرسانی **دستگاه** را بپذیرید. کاربر عادی به نصب دوباره نیاز ندارد. بدون فعال‌سازی TURN، اتصال مستقیم در برخی شبکه‌ها برقرار نمی‌شود. تماس فعلاً خصوصی، دونفره و در همان سرور است؛ سقف مدت ۱۵ دقیقه است. نمایش اعلان به مرورگر، سیستم‌عامل و سرویس Push وابسته است.

آزمایش‌ها شامل دو حساب در اپ کامل، Worker/D1/Durable Object واقعی در محیط محلی، انتقال صدای مصنوعی، دریافت فریم ویدئو، کنترل دستگاه‌ها، پایان تماس و اندازهٔ موبایل و دسکتاپ است. سخت‌افزار واقعی گوشی و مسیر TURN پولی روی شبکهٔ اپراتور در این آزمایش‌ها استفاده نشده‌اند.

راهنمای نصب و تنظیم واسط: [راهنمای تماس](../ADVANCED.fa.md#تماس-و-مصرف-سرویس).
